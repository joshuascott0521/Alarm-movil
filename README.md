# Alarm Móvil

Aplicación móvil de alarmas desarrollada con [Flutter](https://flutter.dev).

## Requisitos

- Flutter SDK (canal stable, Dart 3.x)
- Android Studio / Xcode para emuladores y compilación

## Primeros pasos

```bash
flutter pub get
flutter run
```

## Estructura

- `lib/` — código de la aplicación (`main.dart` es el punto de entrada)
- `test/` — pruebas
- `android/`, `ios/` — proyectos nativos de cada plataforma

## Comandos útiles

```bash
flutter analyze   # análisis estático
flutter test      # ejecutar pruebas
```
